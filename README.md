# ぽくぬり Wedding Celebration! 🎉

[日本語](#日本語) | [English](#english)

---

<h2 id="日本語">日本語</h2>

**ぽくぬり Wedding Celebration!** は、「ぽくぬり」の結婚をお祝いするための、軽量で爽快感のあるミニアプリです。
10秒間の制限時間内に画面をひたすらタップし、お祝いパワー（タップ数）を送ります。

### ✨ 特徴
- **爽快なタップ体験**: 画面をタップするごとに「おめでとう！」「祝」などの文字や紙吹雪のエフェクトが飛び交います。
- **軽量・高速**: Vite + Vanilla TypeScript構成により、極めて軽量かつ高速に動作します（外部のUIフレームワーク非依存）。
- **シェア機能**: プレイ後は、結果に応じた称号が記載された美しい結果画面が表示され、InstagramなどのSNSへ簡単にシェアできます。
- **レスポンシブデザイン**: スマートフォンの縦画面（9:16比率）に美しく収まるデザインです。

### 🚀 遊び方
1. [アプリを開く](https://kenokuda.github.io/Congraturations/)
2. 「タップしてスタート！」ボタンを押して開始します。
3. 10秒間、画面を全力でタップしてください！
4. 結果画面であなたの「お祝いパワー」と「称号」を確認し、シェアボタンからSNSに投稿しましょう！

### 🛠️ 技術スタック
- **Vite** (ビルドツール)
- **Vanilla TypeScript** (ロジック)
- **CSS** (スタイリング・アニメーション)
- **GitHub Actions & GitHub Pages** (CI/CD & ホスティング)

### 💻 ローカルでの実行方法
```bash
npm install
npm run dev
```

<h2 id="english">English</h2>

**Pokunuri Wedding Celebration!** is a lightweight, exhilarating mini-web app to celebrate the marriage of "Pokunuri".
Tap the screen as fast as you can within a 10-second time limit to send your "Celebration Power" (number of taps).

### ✨ Features
- **Exhilarating Tap Experience**: Every tap generates popping text like "Congratulations!" and confetti effects.
- **Lightweight & Fast**: Built with Vite and Vanilla TypeScript for extreme performance with zero UI framework dependencies.
- **Shareable Results**: After playing, a beautiful result card is displayed featuring a unique title based on your score, which can be easily shared to Instagram and other social media via the Web Share API.
- **Responsive Design**: Designed to fit perfectly on smartphone portrait screens (9:16 aspect ratio).

### 🚀 How to Play
1. [Open the App](https://kenokuda.github.io/Congraturations/)
2. Tap the "タップしてスタート！" (Tap to Start) button.
3. Tap the screen as fast as possible for 10 seconds!
4. Check your "Celebration Power" and title on the result screen, and use the share button to post it on social media!

### 🛠️ Tech Stack
- **Vite** (Build Tool)
- **Vanilla TypeScript** (Logic)
- **CSS** (Styling & Animations)
- **GitHub Actions & GitHub Pages** (CI/CD & Hosting)

### 💻 Local Development
```bash
npm install
npm run dev
```
